# Recursos, referencias y alcance

## Base de contenido
Se partió del repositorio de Nicho Agencia Digital, revisión `7719cde2d4c4452dccac9d32ba0d8072d51ca78b`, y de la referencia del usuario “Hyper Tria — Style Reference: chrome monolith in a white gallery”. Se preservan seis proyectos, los datos de contacto y las rutas.

La dirección de arte adapta negro/blanco, tipografía amplia, geometría sin redondear, protagonismo de producto y acentos con funciones definidas. No copia la marca Hyper Branding ni afirma haber reproducido un video que no está en el documento de referencia.

## Animación y recursos
- GSAP 3.12.7 y ScrollTrigger 3.12.7, incluidos en la plantilla Tank suministrada por el usuario. Se preservan las cabeceras de licencia. Revisar la licencia vigente de GSAP: https://gsap.com/community/standard-license/
- Fondo líquido negro/plata: versión recortada y optimizada del recurso Envato entregado por el usuario. No se incluye su ZIP ni su MP4 original de alta resolución.
- Marca NICHO: geometría fija extruida, malla, video y póster generados para este proyecto a partir de las formas de JUST Sans suministradas para el diseño. **No se entrega ni redistribuye el archivo de la tipografía.**
- Favicons, imagen Open Graph y presentaciones de interfaz: composiciones propias de esta entrega. Los datos de demostración no son datos de clientes.

El usuario debe conservar en su Drive los originales y certificados de uso para “NICHO — Web corporativa”. La entrega no constituye una verificación de todas las licencias de su cuenta. No redistribuir los recursos fuente como biblioteca de stock.

## Integraciones
El sitio presenta servicios de Nicho. La demo del flujo no consulta un modelo de IA ni un CRM real. El formulario solo prepara un mensaje para WhatsApp. No hay backend, pagos, API keys ni captura silenciosa de datos.

## Tipografías
La interfaz HTML usa fuentes del sistema. Los archivos de tipografías no forman parte del paquete ni se cargan desde terceros.
