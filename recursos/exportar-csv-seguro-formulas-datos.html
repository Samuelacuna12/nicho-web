Cómo exportar CSV sin activar fórmulas ni alterar identificadores

Exportar una tabla parece sencillo hasta que una hoja de cálculo cambia una referencia o interpreta un texto como fórmula. Un CSV necesita un contrato claro con quien lo recibe: columnas, tipos de datos, uso previsto y controles para contenido que proviene de personas externas.

Define si el archivo será leído por personas o sistemas

Un archivo para importar a otro sistema puede necesitar datos literales, mientras que una hoja destinada a revisión humana debe conservar una presentación comprensible. Pregunta qué herramienta abrirá el archivo y cómo interpreta separadores, fechas y codificación.

Documenta el orden de columnas y la unidad de cada importe o cantidad. Un identificador como 00127 debe seguir siendo identificador, aunque parezca número. Evita fechas ambiguas y comprueba caracteres como tildes y eñes en la aplicación de destino, no solo en un editor de texto.

Trata los textos externos como contenido no confiable

OWASP explica que algunas hojas de cálculo interpretan ciertas celdas como fórmulas y que envolverlas entre comillas no elimina por sí solo ese riesgo. También advierte que el comportamiento cambia según la aplicación y que algunas mitigaciones pueden perderse al guardar y volver a abrir.

Por eso conviene acordar un formato seguro para el destino y probarlo allí. Cuando la prioridad sea la revisión humana, considera un formato que permita definir explícitamente celdas de texto. Si se mantiene CSV, el equipo técnico debe aplicar y verificar la estrategia apropiada sin asumir una protección universal.

Ejemplo hipotético: una lista de solicitudes

Una empresa ficticia exporta nombres comerciales y observaciones ingresadas por clientes. Una observación empieza con un carácter que la hoja interpreta como fórmula. El generador debe impedir que ese contenido se ejecute al abrir el archivo, manteniendo una representación legible para la revisión.

La misma exportación contiene referencias con ceros iniciales y teléfonos internacionales. La prueba comprueba que no se conviertan en cantidades ni cambien de notación. Los valores usados en la prueba son sintéticos; no hace falta copiar una base real de clientes para verificar estas condiciones.

Comprueba el recorrido completo del archivo

  • Genera una muestra con comas, comillas, saltos de línea y caracteres regionales.
  • Incluye textos que la herramienta de destino podría interpretar como fórmulas.
  • Abre, guarda y vuelve a abrir la muestra para comprobar el resultado.
  • Valida que las columnas no se desplacen y que los identificadores conserven su forma.
  • Limita las columnas y filas a lo que el destinatario está autorizado a recibir.

Registra fecha de generación y filtros aplicados cuando ayuden a interpretar la exportación. Si el archivo queda disponible mediante un enlace, define acceso y vencimiento. Un CSV correcto en formato todavía puede revelar demasiada información si la selección de datos fue excesiva.

Cómo encaja con tu operación

Si estas exportaciones se usan para mover datos a una aplicación, revisa la guía de migración con trazabilidad. La seguridad del archivo y la consistencia del proceso de importación deben comprobarse por separado.
