# NICHO AI — Sitio corporativo

Web corporativa **multipágina** de NICHO AI: sistemas empresariales a medida, agentes IA, automatizaciones de ventas y desarrollo web.

## Vista y publicación
Sitio estático (HTML + CSS + JS). Para probarlo localmente, ejecuta `python3 -m http.server 8000` y abre `http://localhost:8000`.

En GitHub: Settings → Pages → Deploy from a branch → main / root. Cuando GitHub Pages esté activo, la URL estimada es `https://samuelacuna12.github.io/nicho-web/`. Este repositorio no afirma que Pages ya esté activo.

## Arquitectura
- `index.html`: home
- `soluciones.html`: catálogo de soluciones
- `sistemas.html`: portafolio
- `proyectos/*.html`: páginas propias para Invicto OPS, Luminari y RestoOps
- `agentes-ia.html`, `automatizaciones.html`, `desarrollo-web.html`: servicios detallados
- `metodologia.html`, `nosotros.html`, `contacto.html`: páginas corporativas
- `assets/styles.css`: diseño responsive
- `assets/site.js`: navegación móvil, scroll y animaciones accesibles

## Diseño y contenidos
Dirección artística: negro carbón, blanco roto, acento lima tenue, gran escala tipográfica, contrastes editoriales, producto como protagonista. Las interfaces ilustradas están etiquetadas como **conceptuales**, sin cifras ni testimonios inventados. Reemplazar con capturas reales antes de producción. Identidad de marca provisional hasta recibir el logotipo oficial.
